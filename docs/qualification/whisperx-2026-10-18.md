## Lessons fixed during the live run

- Cloudflare rejected Python urllib’s default user agent; the worker uses `Societyer-WhisperX/1.0`.
- A standalone shell speech test passed while the hardened systemd worker failed: pyannote tried to inspect `/home/ubuntu/.pyannote/database.yml`, which `ProtectHome` blocked. The service now has a private HOME and explicit model, torch, NLTK and XDG cache paths under its writable directory. The same protected service then completed the live job.
- Two failed synthetic attempts remain in queue history as evidence of this correction. Failed results did not replace the meeting transcript.
- Most diagnostics contain library paths, but libraries can also log source text. Only a bounded last failed-child log is retained privately; general logs and UI get content-free status.
- Zoer’s source-only rollout does not copy a new bundled plugin folder. The host frontend/backend must roll out first, then the Meeting transcription package must be installed/enabled through the existing plugin CLI.
