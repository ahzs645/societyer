## Remaining deployment and feature boundaries

- PowerSync remains selected-meeting preparation. All-module replication, local-vault-to-hosted upload/migration, fully offline hosted authentication and automatic recovery reimport are not implemented by mode switching.
- Real provider credentials/accounts, production TLS/public origins, sync infrastructure privileges and real Clerk/Microsoft tenants need deployment qualification. Configure operator Wave/Paperless bindings before enabling those adapters. Paperless automatic upload needs an actor-aware worker; manual sync remains available.
- Government/CRA submission stays manual through official destinations. Recorded filing status is self-reported; a prepared document, workflow step or uploaded receipt does not establish government verification.
- AI supports bounded TXT/Markdown/CSV/JSON input. PDF/image/office extraction and on-device inference remain unavailable.
- Signed/notarized macOS/Windows installers, real enterprise SSO, physical cameras/devices and Safari remain unqualified. Linux qualification uses an unsigned directory package and fake video without automatic permission approval; AppImage/FUSE support is not established.
- Web/PWA caching supports visited assets. An unseen rich-editor chunk falls back to editable Markdown; an unseen PDF converter uses the existing print fallback. This does not establish every unvisited route or hosted sign-in offline.
- Unknown external submission/file commit outcomes require operator reconciliation; they are not blindly retried. Legacy creatorless AI histories are preserved and fail closed.

Private credentials, fixtures, logs, traces and temporary package profiles stay in ignored paths. Known-secret scanning of public files and generated bundles and `git diff --check` pass. Browser failures that reproduced product defects were fixed; superseded stale-source/harness failures remain explained in the individual artifacts and are not counted twice.
